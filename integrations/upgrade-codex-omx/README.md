# upgrade-codex-omx Integration

This directory contains local artifacts for integrating Codex Afterglow into the user's `upgrade-codex-omx` skill.

## Files

- `skill-step-snippet.md` — the Step 6.5 text to paste into the skill.
- `skill-patch.diff` — a human-reviewable patch sketch for the installed skill.

## Rule

The integration is semi-automatic: verify and dry-run are automatic; actual binary replacement requires explicit user confirmation.
